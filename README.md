# Sistema de Inventario de Equipos

Aplicación de escritorio desarrollada en Python con interfaz gráfica (Tkinter),
orientada al control de equipos de cómputo en áreas administrativas y de soporte técnico.

## Funcionalidades
- Registro de equipos
- Visualización en tabla
- Cambio de estado (Disponible / En uso)
- Interfaz gráfica sencilla y funcional

## Tecnologías
- Python 3
- Tkinter

## Uso
Ejecutar el archivo:

python3 inventario_gui.py
